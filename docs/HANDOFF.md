## 6. iPhone Safari でつまずいた所（必読）

### 振動
- iPhone の Safari は `navigator.vibrate` が使えない。iOS 18 から「スイッチ型チェックボックス（`<input type="checkbox" switch>`）を切り替えると触覚フィードバックが出る」ので、それを使う（非公式。iOS の「システムの触覚」が ON のときだけ）
- 押せる要素に**透明な `<label>`（中に非表示のスイッチ）をかぶせ、指のタップそのものでスイッチを切り替える**。プログラムからの `label.click()` は WebKit の修正で振動しなくなったので使えない
- **振動はタップが click になったときだけ**出る。次のときは click にならず振動しない
  - **指を離した瞬間（pointerup）に画面を大きく描き直す**と、iOS はそのタップを click にしない → 画面の切替などは **click の時**に行う（ハナハナの機種名タップでこれが原因で「振動しない」と言われ、click の時に切り替えるよう直した。click が来なければ 0.4 秒後に予備で切り替える）
  - 長押しで押している間にパネルを開くと、離しても click にならない（ハナハナの機種名長押しは振動なしのままにした）
- ラベルが中のスイッチへ送る **2回目の click** を要素の onclick まで届かせると処理が2回動く → ラベルの onclick で止める
- 押した瞬間に自分を描き直す要素は振動用ラベルも消えるので、中身だけ書き換える
- 押せるものには全部付ける（`addHaptics` が決まったセレクタの要素に自動で付ける。新しいボタンを足したらセレクタに入るか確認）
- コードは `snippets/tap-and-haptic.js`

### タップの数え方（カウンターの肝）
- 加算は **pointerup** で行う。iOS が pointerup の代わりに pointercancel を送ったり、pointerup が届かないことがあるので、**振動用ラベルの click が来たら（＝振動したら）そこで数える（click 補完）**。1回の押下で1回だけ
- **長押し 300ms で赤くなり −1**。指を 50px 以上動かしたらキャンセル（スクロールとみなす）
- 「＜ベル＞」のような見出し（セルの外）を押すと、iOS のタップ位置補正で近くのセルに click だけが届く → **そのセルで押し始めていない click は打ち消す**（`preventDefault` してスイッチも切り替えない）
- ポインタキャプチャは**マウスだけ**（タッチでキャプチャすると click の宛先がセルになりスイッチが切り替わらない）
- 調査用に「操作ログ」（直近20件、どのイベントが来たか）を管理画面に出しておくと、「振動したのに数えない」などの原因を実機のスクリーンショットで調べられる

### そのほか
- ダブルタップの拡大を止める: viewport に `maximum-scale=1.0, user-scalable=no`、`dblclick` の `preventDefault`、`touch-action: none`（モーダルの中だけ `pan-y`）
- 横画面の文字拡大を止める: `-webkit-text-size-adjust: 100%`
- 入力欄は **font-size 16px 以上**（未満だと iOS がズームする）。入力中に画面を作り直すとフォーカスが外れるので、入力欄の値を確定するときは画面を描き直さない（ハナハナの `save(true)`）
- 入力モードとダミー表示（本当の数を隠す表示）を両方使うと入力欄を出せない、という作りにしていて「入力できない」と報告された。隠すものが無い欄（打ち始め）は入力できるようにした
- **複数タブ**: iOS ショートカットから URL で値を送ると Safari が新しいタブを開く。古いタブが古いデータで上書きしないよう、**最後に開いたタブだけ保存できる**ようにする（`snippets/storage-and-tabs.js`）
- safe-area（ノッチ・ホームバー）は `env(safe-area-inset-*)` で余白を取る

## 7. スプレッドシート連携

- GAS は `gas/Code.gs`（ハナハナと同じ作り。シート名と TOKEN を変える）。スプシの「拡張機能 → Apps Script」に貼り、「デプロイ → 新しいデプロイ → ウェブアプリ（実行: 自分 / アクセス: 全員）」。発行された URL とトークンをアプリの管理画面に入れる
- **GAS を変えたら「デプロイを管理 → ✏️ → バージョン: 新バージョン」で再デプロイ**（URL は変わらない）。忘れると古いコードが動き続ける（ハナハナで原因不明バグの正体だった）。GAS の変更は再デプロイの手間があるので、なるべく GAS を変えずに済む作りにする
- アプリからの保存は `POST`、本文は JSON、**`Content-Type: text/plain`**（CORS のプリフライトを避ける）。取得は `GET ?action=getAll&token=…`
- `TOKEN` はアプリの設定と一致させる。不一致は `{"error":"unauthorized"}`
- シートが無ければ GAS が見出し付きで作る（アプリが見出しも送る）
- **列の定義はアプリの1か所**（ハナハナの `sheetColumns(m)`）。保存・TSV コピー・読み込み・見出しを全部そこから作る（バラバラに持つと列がずれる）
- **生データだけ保存**（集計・推測は読み込み時に計算）。記録していない項目は空欄（0 は「記録して0回」）
- 1回ごとの記録（ハナハナの当選履歴）は1つのセルに文字列で入れて、読み込みで戻す（例「B120 R45[チェリー] B30[フリーズ・バイブ]」）
- GAS は**日付のセルを `yyyy/MM/dd HH:mm` の文字列**にして返す。getAll は「2列目が空でなく、3列目が数値」の行だけ返す（見出し・空行を飛ばす）
- **A 列にメモ**を置くなら、アプリは空欄で保存し、メモはシートで書く。列を足した前後の行を両方読むときは「B 列が日付か」で見分ける（ハナハナの `rowHasMemo`）
- xlsx から変換したとき、数値の列に日付の書式が残っていて総回転数が日付として読まれた事故があった（書式も直す）
- 集計シート（ハナハナの「歴代記録」）は式（`SUM` / `SUMIFS`）で各機種シートを参照する。機種シートに列を挿入しても式は自動でずれる
- ユーザーのスプシの書き出し（xlsx）は個人データなので**コミットしない**（`.gitignore` に `*.xlsx`）
- コードは `snippets/sheet-sync.js`

## 9. Windows の開発環境でつまずいた所

- **改行コード**: 新しいリポジトリは全部 LF にする（`.gitattributes` の `* text=auto eol=lf`）。ハナハナの index.html は CRLF で、置換のたびに気を使った
- Git Bash の `sed -i` は改行を変えてしまう → ファイルの編集は Edit ツールか Python（バイト列で読み書き）
- **Bash のヒアドキュメントの中では `\\` が `\` になる**（`'\\t'` が本物のタブになった）→ バックスラッシュを含む置換は Write ツールでスクリプトファイルを作ってから実行し、書いた後に確かめる
- 改行の確認は Python でバイト数を数える（Git Bash の `grep -c $'\r$'` は LF だけのファイルでも全行を数えて当てにならない）か `git ls-files --eol`
- **Codex CLI**: PATH に無い。`C:\Users\t5kzm\AppData\Local\OpenAI\Codex\bin\<ハッシュ>\codex.exe`（ハッシュは更新で変わる）。PowerShell で
  ```
  Get-Content prompt.md -Raw -Encoding utf8 | & $codex exec -s read-only -C <リポジトリ> -o out.md --color never -
  ```
  をバックグラウンドで。エフォートを下げるときは `-c model_reasoning_effort="medium"`（または `"low"`）。1回十数分。「完了」の通知が早く来ることがあるので、`-o` のファイルができるまで待つ。上限に達すると止まる（出力ファイルができない）。依頼文には「ファイルを変更しない」「個人データ（xlsx）を開かない」「要望と確定した仕様」「観点」を書き、指摘は鵜呑みにせず実コードで確かめる
- ブラウザのプレビュー（preview_start）は固まるので使わない

## 12. ハナハナで実際に起きた事故（同じことをしないために）

- 表示用の数値だけ直して計算用を直し忘れた（3回）→ 二重に持つ値はテストで突き合わせる
- 押す前の状態に戻す処理（取り消し）で、区間の G 数の繰り入れ先を古い側にして誤った → 時系列を図にしてから期待値を決める
- 「振動したのに数えない」→ click 補完と、枠外の click の打ち消し（「6.」）
- 古いタブが新しいデータを上書きした → 使えるタブだけ保存
- GAS の再デプロイ忘れで古いコードが動き続けた
- シートの列をいじったら過去の行が読めなくなりかけた → 列の定義を1か所にし、並びを変えたら古い並びの行の読み方をテストで確かめる
- テストの期待値そのものを間違えて「OK」と報告した → 期待値は意味から自分で導く
